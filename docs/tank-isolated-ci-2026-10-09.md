# Isolated Tank Diagnosis

Parent: c6a050c1dad7438b3870df077cd097063aaf488a.
The optional workflow_dispatch tank_only input runs the existing complete tank
job, including ordinary two/four peers, tournaments and both recorded finals.
Its concurrency suffix is distinct from the full matrix and core-only lane.
The default remains the full 40-scenario matrix: core plus all 39 games.
No injury, reconnect, result-equality or map-coverage assertion is removed.

Conflicting diagnostic selectors fail before asset installation; the balance
job does not launch when a diagnostic selector is also selected. Static YAML
parsing, default/matrix checks and shell-selector truth-table checks are local
configuration evidence, not proof of successful execution on GitHub.

The isolated tank lane is diagnostic evidence only. It cannot sign off all
games, replace full current-source network qualification, approve main merge
or permit App Store submission on its own. Existing campaigns must not be
cancelled just to dispatch a newer source in their concurrency group.
