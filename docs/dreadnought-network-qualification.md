# Dreadnought world adapter qualification (2026-10-03)

## Implemented

Starting source: `f9883790968d3bbc439d925fa070c89dbfda3fd3`.

- `dreadnought_replica.gd` captures the host boss health/phase/pose and feedback
  sequences, visible warnings, mine arming state and active shell poses.
- Snapshots have strict field counts, finite bounded values, unique canonical
  object IDs, normalized shell directions and bounded object populations.
  Boss phase and defeat must agree with health and the authored thresholds.
- Shared boss capture/validation and warning validation reuse Forge helpers.
  Forge's existing wire format is unchanged.
- MatchReplica captures, validates and renders the new world. Guest views are
  meshes without collision bodies or rule callbacks. Removed objects are
  pruned; replacing a replica retires its old view. Baselines do not replay
  historical audio; sampled new damage plays once.
- Presentation-only guards prevent guest Dreadnought callbacks from changing
  targeting, spawning shells/mines, scoring vent hits or resetting the round.
- The server has a matching `validDreadnoughtWorld` validator. CI requires a
  fresh actual Godot capture for its schema test, not just synthetic fixtures.
