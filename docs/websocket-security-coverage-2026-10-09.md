# فحص التبعيات وحدود WebSocket

9 أكتوبر 2026؛ كود التشغيل لم يتغير. أضيفت خمسة اختبارات إلى
`server/multiplayer-security.test.js` لتغطية السلوك الموجود فعليًا:

- الشبكات معطلة افتراضيًا، بما في ذلك العميل الأصلي الذي لا يرسل Origin.
- مطابقة Origin حرفيًا مع allowlist، رفض أصل مختلف أو نطاق مشابه أوnull،
  وقبول الأصل المعتمد والعميل الأصلي.
- رفض ترقية مسار مختلف، أوشرطة ختامية، أوquery في المسار.
- إغلاق الرسائل الثنائية بكود1008 دون إنشاء غرفة.
- JSON غير صالح يعيد رمزخطأ ثابتًا دون إعادة محتوى الرسالة أوعلامة canary.

يُستخدم عنوانlocalhost ومنفذ مؤقت؛ لا وصول إلى قاعدة الإنتاج أوبياناتها.
هذا ليس إثباتًا لأمان شامل أوتكوين Railway الفعلي أوحماية كل أصناف إساءة الاستخدام.
غيابOrigin في العميل الأصلي مقبول حسب التصميم؛ الاختبارات لا تدعي أنه هوية موثقة.
