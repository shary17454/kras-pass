# Full boss AI regression qualification

## Scope (2026-10-03)

The starting source was `3a5bc0099d1da36a059bba99fa7f42021c8b10a3`.
The changes in this commit extend the existing full-match Colossus harness
with an allowlisted `--game` parameter and add Forge, Dreadnought and
Sovereign to `tools/check_party.sh`. The default Colossus invocation remains
compatible. The three existing Colossus seeds remain in the gate.

Each added match uses four Expert bots, the existing Sakhra/Fanoos/Ramla/Nabta
roster, seed 9614 and one round. Health, damage, AI tuning and the authored
150-second round duration are not overridden. The 220-second harness
watchdog is only an upper bound on waiting for the normal result callback.
Passing requires both that callback and `boss_defeated`; timing out with an
undefeated boss is a failure. No test directly damages or moves the boss.

## Limits and remaining requirements

This is a repeatable completion regression, not a balance simulation. In
particular, one Forge bot scored zero in the tested seed. This does not prove
fair contribution, all character combinations, all difficulties or all seeds.
These matches are headless local simulation, not human playtesting, physical
iPhone/iPad FPS, battery or thermal testing, and not Internet multiplayer.

Colossus, Dreadnought and Sovereign still need their online world replication
adapters and real multi-peer/reconnect qualification. This change does not
enable them in the online allowlist or enable production online play.
Railway deployment, signed archive, App Store upload and review submission
were not performed by these checks.
