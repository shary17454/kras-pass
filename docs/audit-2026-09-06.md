# Engineering audit - 2026-09-06

Base commit: `5f24368`. Changes are local; no submission or push performed.

## Verified fixes

- Save failures retain dirty state for a later retry; failed writes no longer
  emit a successful-save signal. File flush and rename results are checked.
- Invalid envelope field types are rejected before typed conversion.
- Saving after backup recovery no longer replaces the good backup with the
  corrupt main file.
- Regression tests cover failed-write retry, malformed envelopes and backup
  preservation after recovery.
- iOS export uses an isolated directory instead of deleting checked-in iOS
  archive parts required by Xcode Cloud. Shell syntax and a simulator build pass.
- The user-provided icon replaces all 15 source sizes and all 16 Xcode catalog
  entries. The 1024px PNG is opaque. The asset generator uses the approved
  image instead of regenerating the previous branding.
- Store screenshots and design sources are excluded from the iOS game pack.
  This exclusion was added after the simulator export and needs a fresh export.
- Arctic foam uses one MultiMesh instead of 54 separate mesh nodes, retaining
  the wave positions and animation. The perf probe can save actual renders
  with `--screenshots` and pauses its callback while capturing/tearing down.

## Validation

- Compile check: 165 scripts pass.
- Full automated suite after save fixes: 1252 assertions pass. Includes all
  38 registered games, including boss encounters, plus save, replay, input,
  scoring, progression, lifecycle and race-condition tests.
- Real-window layout check: 32 screens pass across Arabic and English at
  1920x1080. This is not a check of every phone/tablet size or VoiceOver.
- Performance sweep: all 34 selectable games completed the probe. The four
  boss encounters are not included by `perf --all`; they are in integration tests.
- Scene nodes return to 45 after the sweep, equal to the starting count.
- Standalone arctic measurements on Apple M5 / Metal Forward+ / 1920x1080:

| --- | --- | --- |
| Ring Rumble | 17.94 / 22.22 ms | 13.09 / 14.46 ms |
| Drift Floes | 18.41 / 23.33 ms | 13.80 / 15.28 ms |

These are individual desktop runs, not a controlled multi-run benchmark or
iPhone thermal certification. Earlier full-sweep results overlapped other
verification processes and are unsuitable for precise before/after comparisons.
Actual post-change render captures were inspected for both arctic games.

- Xcode 26.6 / SDK 26.5 simulator Release build succeeded (96 MB, x86_64,
  iOS minimum 15, iPhone and iPad). Built before the foam change, so not a
  final release artifact. Installation failed because the booted simulator
  requires arm64 while the available Godot simulator library contains x86_64.
