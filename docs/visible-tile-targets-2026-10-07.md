Paint and colour controllers previously searched every tile without an
observation filter. A hidden nearest tile beat an observable alternative.
Colour AI also retained a hidden committed tile and stale movement when no
eligible tile was observable. The regression uses actual scene tiles and
actual AI observation logic across all four difficulty levels.

The optional query predicate preserves existing unfiltered calls by network
fixtures and gameplay tooling. AI supplies `can_observe`; dynamic tile state
is inspected only after passing it. Colour commitment is revalidated before
reading its current state. No character statistics, call reaction delay,
round rules, network payloads or scoring were changed.
