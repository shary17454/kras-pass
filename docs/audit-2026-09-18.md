# Engineering audit - 2026-09-18

Base commit: `5ed1a86`. All changes below are pushed to `main`.

## Verified fixes

- `tank_world.gd` / `natural_valley.gd`: a rock-mesh source that failed to
  load left `_rock_meshes` empty, and `_rock()` / `_cover()` then indexed it
  unconditionally — `posmod(n, 0)` and an out-of-bounds array read, both
  crash-adjacent. Guarded both call sites and added an explicit error log so
  a real load failure is now visible instead of silent.
- `AIBrain.predict()` read a rival's **live, undelayed** velocity while its
  position came from the delayed perception history — a real breach of the
  project's own "an AI may only read what a human can see, after a
  human-plausible delay" rule. Added a velocity history ring buffer
  alongside the existing position one; `predict()` now reads both from the
  same delayed instant. Swept all 19 brains for the same class of leak —
  no other rival-state read bypasses `perceive()`/`predict()`.

## Additions

- **Cosmetics / Customize**: `data/cosmetics.json` (5 palettes, 4 titles),
  each unlocked through the existing `Progression._rule_met()` engine — no
  new unlock logic, no new art. `PlayerConfig.character_with_cosmetics()` is
  the single integration point in `match_scene.gd`; AI opponents are never
  recoloured. New `customize` screen, linked from the main menu and profile.
- **Credits screen** + an explicit **Quit** button with confirmation on the
  main menu. `menu.quit` was a translated string with no button wired to it.
- **Leader indicator**: `EventBus.lead_changed` was declared, never emitted,
  never listened to. `MatchScene` already computed lead changes for the
  replay highlight reel; it now also emits the signal, unconditionally (not
  only when replay capture is on), and `MatchHUD` shows a 👑 on the current
  leader's chip.
- Removed six verbatim-duplicate helpers across `gem_grab.gd`, `star_rush.gd`,
  `crate_relay.gd`, `base_siege.gd`, `relic_hold.gd`, `tag_hunt.gd` in favour
  of two new `MiniGameController` helpers (`player_name()`, `count_live()`).
  README's "adding a mini-game" section documents both.
- Ring Rumble: characters are 18% larger in this game only, via a new
  `Fighter.set_game_scale()` channel kept independent of the mutator and
  power-up size channels.

## Validation

- Godot 4.7.1 (matches the project's stated dev version) headless, run
  fresh in this environment for every batch above.
- Compile check: 202 scripts pass (grew from 200 with the two new screens).
- Full automated suite: **7887 assertions pass**, run clean after every
  batch, including a final run against the combined diff. No regressions.

## Outstanding

- **Performance was not measured this session.** `tests/perf.gd` and the
  perf probe need a real display and GPU — this environment is headless
  with Godot's dummy renderer, and numbers from it would be fabricated, not
  measured. The project's own rule is not to optimize on a guess. This needs
  a machine with an actual GPU (the 2026-09-06 audit used an Apple M-series
  Mac); pick it up there when one is available, using the same before/after
  methodology already established in `docs/audit-2026-09-06.md`.
- No new Apple review submission, no device test, no real-window layout
  check was performed. Nothing outside the items listed above was audited
  or changed.
