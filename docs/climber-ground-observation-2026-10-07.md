## Implemented

Rising Tide ground discovery now observes the configured reaction delay,
using instance-keyed position histories capped at 32 samples per object.
Only currently observable geometry can supply a new target; no premature
fallback reveals its current position. Round start and reconfiguration clear
the route and observation credit. A replacement instance cannot inherit
the old object's credit. Previously observed route memory remains legitimate
even when the object becomes hidden; hidden movement is not read.

No movement, scoring, character stats, physics, network schema, saves or
production configuration changed. Static arena geometry remains finite;
this change does not claim a global cache bound for unlimited dynamic IDs.
